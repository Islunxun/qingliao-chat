# 轻聊：匿名在线聊天室

一个无需注册的实时网页聊天室，支持：

- 匿名进入、文字与表情消息
- 图片发送（单张不超过 2 MB）
- 新建多个聊天室
- 同一网站上多位访客即时收发消息
- 服务不可用时自动切换为浏览器本地演示模式

## 本地运行

本项目使用 Node.js 18 或更新版本，且不需要安装任何第三方包。

```powershell
node server.js
```

然后在浏览器打开 `http://localhost:3000`。

## 发布到网站

把整个 `anonymous-chat` 文件夹部署到支持 Node.js 的服务（例如 Render、Railway 或自己的服务器），设置启动命令为：

```text
node server.js
```

可通过环境变量 `PORT` 设定端口。当前版本将消息保存在服务器内存中，重启服务会清空记录；生产使用时应接入数据库和对象存储。

## 房主管理

在部署平台的环境变量中新增 `ADMIN_PASSWORD`，值填入你自己设定的房主密码。网站右上角的“房主”按钮即可登录管理模式：删除消息、禁言昵称和发布公告。

不要把房主密码写入 `server.js`、`index.html` 或上传到 GitHub。
